DPTiny Architecture

Class hierarchy, compute graph, and backpropagation flow

1. Class Architecture

DPTiny is built around three core abstractions: Variable wraps array data and gradients, Function defines a forward operation and its local backward rule, and Layer owns learnable parameters used by models.

Variable

Holds data, grad, and a creator function. It is the node of the compute graph.

Function

Encapsulates a forward operation and how to back-propagate local gradients via backward().

Layer

Holds learnable parameters (params) and composes Functions into network building blocks.

Config

Global flag enable_backprop; disabled during inference by the no_grad() context manager.

2. The Compute Graph

Operations on Variables build a directed acyclic graph. Each function records its inputs and weak references to its outputs, enabling gradient propagation from loss to parameters.

3. Forward Pass

Function.__call__ performs three things: (1) converts inputs to Variables, (2) runs forward() on raw arrays, and (3) wraps the result, records the creator, and increments the generation. 

class Function(ABC):
    def __call__(self, *inputs):
        inputs = [as_variable(x) for x in inputs]
        xs = [x.data for x in inputs]
        ys = self.forward(*xs)
        outputs = [Variable(as_array(y)) for y in ys]

        if Config.enable_backprop:
            self.generation = max(x.generation for x in inputs)
            for output in outputs:
                output.creator = self
            self.inputs = inputs
            self.outputs = [weakref.ref(output) for output in outputs]

        return outputs[0] if len(outputs) == 1 else outputs

4. Backward Pass (Backpropagation)

Variable.backward() walks the graph in reverse topological order using a max-heap keyed by generation. At each function, output gradients are gathered and passed to the function's backward() to compute input gradients. Gradients are accumulated when a variable is used multiple times. 

def backward(self, retain_grad=False):
    if self.grad is None:
        self.grad = xp.ones_like(self.data)

    heap = []
    seen_set = set()
    counter = 0

    def add_func(f):
        if f not in seen_set:
            heapq.heappush(heap, (-f.generation, counter, f))
            seen_set.add(f)

    add_func(self.creator)

    while heap:
        _, _, f = heapq.heappop(heap)
        gys = [output().grad for output in f.outputs]
        gxs = f.backward(*gys)
        if not isinstance(gxs, tuple):
            gxs = (gxs,)

        for x, gx in zip(f.inputs, gxs):
            x.grad = gx if x.grad is None else x.grad + gx
            if x.creator is not None:
                add_func(x.creator)

    x = Variable(x)
    y = model.forward(x)

    model.cleargrads()

    optimizer.update(model.params)

6. GPU Backend

DPTiny abstracts NumPy/CuPy through a single xp backend. Calling use_gpu() makes all array creation and math run on the GPU while the autograd engine itself stays unchanged.
